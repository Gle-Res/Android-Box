## 📖 项目简介

**AndroidBox** 是一款专为 Windows 打造的安卓应用安装工具，基于 Windows Subsystem for Android（WSA）与 ADB 技术，让你在电脑上轻松安装并运行 Android APK，无需第三方模拟器，也无需手动敲命令。

### 核心亮点

- 🚀 **轻量小巧**：全程仅占约 **2GB**，比传统方案节省约 40% 空间
- 🎯 **一键安装 WSA**：内置安装引导，无需手动配置环境
- 🛍️ **内置应用商店**：可直接从豌豆荚下载 APK，也可选择本地文件安装
- 📟 **实时终端输出**：安装过程全程可见，失败原因一目了然
- 🔍 **设备自动检测**：自动连接 WSA 的 ADB，无需手动 connect
- 📥 **下载进度与速度**：实时显示 APK 下载进度和速度
- ⚡ **安装后自动启动**：APK 安装完成后自动打开应用
- 🧹 **退出自动清理**：关闭程序时自动结束 adb 进程，不留残留

### 和腾讯应用宝的区别

| 对比项 | AndroidBox | 腾讯应用宝 |
|--------|-----------|-----------|
| 占用空间 | **约 2GB** | 约 5GB |
| 技术底层 | 直接调用 WSA + ADB | 私有引擎封装 |
| 应用来源 | 完全开放，任意 APK | 官方分发，限制较多 |
| 部署门槛 | 需手动配置（本教程） | 双击即用 |
| 后台服务 | 无 | 有常驻更新/推送 |
| 广告与推荐 | 无 | 有 |

> **AndroidBox 更像是一把给懂行的人准备的瑞士军刀，应用宝则是给大众准备的官方超市。**

## ⚠️ 注意事项

## 🛠️ 安装教程

### 一、安装前准备

#### 1. 解压程序到合适的位置

- 将程序**解压到无中文、无特殊符号的路径**下。
  - ✅ 正确示例：`D:\AndroidBox`
  - ❌ 错误示例：`D:\我的软件\安卓工具箱（新）`
- **程序所在位置不可移动**，否则程序将无法正常运行。
- 建议整个文件夹固定不动，后续所有操作均以该文件夹为准。

#### 2. 开启硬件虚拟化

1. 重启电脑，进入 BIOS / UEFI 设置界面。
2. 找到 **Virtualization Technology（VT-x / AMD-V / SVM）** 选项并开启。
3. 保存设置并重启进入 Windows。
4. 打开 **任务管理器 → 性能 → CPU**，确认底部显示 **虚拟化：已启用**。

> 如果显示「已禁用」，请返回 BIOS 检查是否保存成功。

#### 3. 开启 Windows 必需功能

1. 按 `Win + R`，输入 `optionalfeatures`，回车。
2. 在弹出的「Windows 功能」窗口中，勾选以下两项：
   - ✅ **适用于 Linux 的 Windows 子系统**
   - ✅ **虚拟机平台**
3. 点击「确定」，等待系统完成功能安装。
4. **重启电脑**，使更改生效。

---

### 二、安装适用于 Android 的 Windows 子系统（WSA）

1. 双击运行 `AndroidBox.exe`。
   - ⏳ 首次启动可能较慢，请耐心等待。
2. 在程序左侧菜单中，点击 **「安装适用于 Android 的 Windows 子系统」**。
3. 点击右侧 **「开始安装」** 按钮。
4. 安装过程中可能弹出授权提示，按提示允许即可。

#### 安装完成后的必要配置

安装完成后，从 **开始菜单** 打开 WSA 程序，按以下步骤配置：

**① 关闭恶意应用拦截**

- 进入 WSA 设置，关闭 **「阻止安装恶意应用」**。

**② 开启开发人员模式与 ADB**

1. 进入 **高级设置**。
2. 打开 **开发人员模式**。
3. 确认 **ADB 连接地址** 为 `127.0.0.1:58526`。
4. 点击蓝色小字 **「管理开发人员设置」**。
5. 在打开的页面中，确认 **USB 调试** 已开启。
   - ⏳ 打开该页面可能较慢，请耐心等待。

**③ 开启本地网络访问**

- 展开 **实验性功能**，打开 **本地网络访问**。

**④ 设置资源分配**

- 展开 **内存和性能**，将 **子系统资源** 选为 **始终分配**。

> 以上配置完成后，建议**重启一次 WSA**，确保设置生效。

---

### 三、安装 APK

#### 方式一：通过应用商店下载（推荐）

1. 在 AndroidBox 左侧点击 **「应用商店」**。
2. 浏览并选择想要安装的应用，点击下载。
3. 下载完成后，程序会自动选择保存位置，你也可以手动指定。

#### 方式二：安装本地 APK

如果你已有现成的 APK 文件，可直接跳过商店，按下面步骤安装。

---

### 四、安装 APK 到 WSA

1. 在 AndroidBox 左侧点击 **「安装 APK 程序」**。
2. 点击右侧 **「选择 APK 并安装」**。
3. 选择你要安装的 APK 文件。
4. 等待程序执行 `adb connect` 与 `adb install`。
5. 当提示 **安装成功** 后，即可在 **Windows 开始菜单** 中打开已安装的安卓应用。

## ❓ 常见问题（FAQ）

**Q1：点「开始安装」后没有反应？**
- 确认已开启虚拟机平台与适用于 Linux 的 Windows 子系统功能。
- 确认 BIOS 中硬件虚拟化已启用。

**Q2：ADB 连接失败怎么办？**
- 确认 WSA 已启动。
- 确认 WSA 中开发人员模式与 USB 调试均开启。
- 确认 ADB 地址为 `127.0.0.1:58526`。
- 若仍失败，可在程序「安装 APK 程序」页面点击 **「检测设备」** 重试。

**Q3：程序无法移动位置？**
- 是的，本程序依赖同目录下的 `adb` 与 `WSA` 文件夹，**位置移动后路径会失效**。请保持文件夹结构完整、位置固定。

**Q4：启动很慢？**
- 首次启动需要加载依赖，属于正常现象。之后的启动会快一些。

**Q5：安装 APK 时提示连接失败？**
- 请确认 WSA 正在运行，且已开启 ADB 调试。
- 可以尝试在 WSA 设置中重启一次子系统。
